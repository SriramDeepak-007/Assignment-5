# Assignment 5

This repository contains Python programs that demonstrate the use of dictionaries, lists, strings, user input, conditional statements, and list slicing.

---

## Task 1: Create a Dictionary of Student Marks

### Problem Statement

Write a Python program that:

1. Creates a dictionary where student names are keys and their marks are values.
2. Asks the user to enter a student's name.
3. Retrieves and displays the corresponding marks.
4. Displays a message if the student is not found in the dictionary.

### Functionality

The program stores student names and their marks in a dictionary. The user enters a student's name, and the program checks whether the name is present in the dictionary. If the name is found, the student's marks are displayed. Otherwise, the program displays a message saying that the student was not found.


## Task 2: Demonstrate List Slicing

### Problem Statement

Write a Python program that:

1. Creates a list of numbers from 1 to 10.
2. Extracts the first five elements from the list.
3. Reverses the extracted elements.
4. Prints the extracted list and the reversed list.

### Functionality

The program creates a list containing numbers from 1 to 10. It uses list slicing to get the first five elements and then uses slicing again to reverse those elements. The original list, extracted list, and reversed list are displayed.
